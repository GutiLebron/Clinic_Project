# Clinic_Project
Este proyecto es un MVP de una aplicación clínica desarrollada sobre tecnología ABAP Cloud utilizando el modelo RAP (Restful ABAP Programming Model).
El objetivo es mostrar cómo se construye una solución empresarial real: organizada, escalable y preparada para crecer con nuevas funcionalidades.


Objetivo del proyecto
Crear una aplicación que gestione:

Pacientes
Citas
Médicos
Especialidades

Todo ello siguiendo buenas prácticas de diseño, arquitectura y organización del código. Este proyecto tiene como principal fin el aprender nuevas herramientas
que nos presta el modelo RAP tanto a nivel visual como técnico y repasar otras que he ido aprendiendo.
